# Contract: личные файлы в сессии (C-F*)

## Объявление

```toml
[files]
".gitconfig" = "~/dotfiles/gitconfig"              # известное имя
".config/nvim" = "~/.config/nvim"                  # каталог под XDG
".myrc" = { source = "~/.myrc", env = "MYTOOL_RC" }  # переменная названа явно
".netrc" = { source = "~/.netrc", secret = true }    # разрешённый секрет

[hosts.web.files]
".gitconfig" = "~/dotfiles/gitconfig-work"         # заменяет глобальную
".config/nvim" = false                             # на этом хосте не нужна
```

- **C-F1**: ключ — имя, под которым файл искала бы программа в домашнем каталоге;
  значение — путь на клиенте (файл или каталог) либо таблица `source` (обязателен),
  `env`, `secret`. `~/` — домашний каталог клиента; относительный путь — от него же.
- **C-F2**: имя — относительный путь: без ведущего `/`, без `..` и пустых
  сегментов, без `"`, `` ` ``, `$`, `\` и переводов строки. `env` —
  `[A-Za-z_][A-Za-z0-9_]*`. Нарушение — ошибка config (40) до подключения.
- **C-F3**: действующий набор для цели — `[files]`, поверх него
  `[hosts.<цель>.files]` по имени записи; `false` у хоста исключает запись.
  `xxh config show [--host …]` печатает действующий набор.

## Доставка

- **C-F4**: каждая запись вне `.config/` — отдельный компонент; все записи под
  `.config/` — один компонент. Адрес — по содержимому: неизменившийся компонент не
  передаётся; изменение одной записи вне `.config/` передаёт только её.
- **C-F5**: файлы размещаются только в `<root>/cache/<адрес>`; домашний каталог
  цели не читается и не изменяется. Права файлов сохраняются. Очистка, `--keep`,
  проверка целостности, `xxh status`, `xxh clean --stale` — как для прочих
  компонентов.
- **C-F6**: видимость программам:

  | Имя | В сессии |
  | --- | --- |
  | `.config/<…>` | `XDG_CONFIG_HOME` — каталог с доставленными `.config`-записями |
  | `.gitconfig` | `GIT_CONFIG_GLOBAL` |
  | `.inputrc` | `INPUTRC` |
  | `.vimrc` | `VIMINIT='source <файл>'` |
  | `.screenrc` | `SCREENRC` |
  | `.wgetrc` | `WGETRC` |
  | `.curlrc` | `CURL_HOME` (каталог с файлом) |
  | `.npmrc` | `NPM_CONFIG_USERCONFIG` |
  | `.psqlrc` | `PSQLRC` |
  | `.ripgreprc` | `RIPGREP_CONFIG_PATH` |
  | `.editrc` | `EDITRC` |
  | любое с `env = "VAR"` | `VAR` — путь доставленного файла или каталога |

  `env` у записи имеет приоритет над таблицей.
- **C-F7**: запись, для которой способа нет (нет в таблице, не под `.config/`, без
  `env`), не доставляется; предупреждение называет её и подсказывает `env` или
  размещение под `.config/`.

## Предупреждения (stderr, до подключения, `xxh: warning: files: …`)

- **C-F8**: источника нет на клиенте — запись пропущена, сессия продолжается.
- **C-F9**: запись похожа на секрет (по имени файла или каталога, либо по
  PEM-заголовку приватного ключа; в каталоге — любой файл) — не доставляется;
  названы файл и `secret = true`. С `secret = true` доставляется без предупреждения.
- **C-F10**: запись больше 10 МиБ — предупреждение с размером; доставляется.
- **C-F11**: симлинк в объявленном каталоге, ведущий за его пределы, пропускается;
  предупреждение называет его. Симлинк внутрь каталога доставляется как файл или
  каталог, на который он указывает.
- **C-F12**: содержимое файлов не выводится ни в предупреждениях, ни в журналах на
  любом уровне подробности.

## Генераторы

- **C-F13**: модули Home Manager и NixOS принимают `files` и `hosts.<имя>.files`
  тех же видов и порождают те же ключи `config.toml`.
