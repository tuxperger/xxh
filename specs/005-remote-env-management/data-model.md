# Data Model: Управление сохранённым окружением на цели

## RemoteEnv (одна запись на найденный каталог окружения)

| Поле | Смысл |
|---|---|
| `root` | путь каталога окружения на цели (`…/.xxh`) |
| `kept` | есть `.keep` — окружение сохранено флагом `--keep` |
| `last_used` | секунды Unix из `.keep`, либо нет данных |
| `size_kb` | объём каталога по `du -sk`, либо нет данных |
| `sessions` | список `SessionMarker` |
| `components` | список `StoredComponent` |
| `other` | прочие элементы в корне и `cache/` (временные файлы, `run/`), имена |

## SessionMarker

| Поле | Смысл |
|---|---|
| `id` | имя маркера в `sessions/` |
| `pid` | pid из маркера (может отсутствовать) |
| `active` | `kill -0 pid` успешен |

## StoredComponent

| Поле | Смысл |
|---|---|
| `hash` | адрес (имя каталога в `cache/`) |
| `size_kb` | объём, если доступен `du` |
| `state` | `current` — адрес есть в плане клиента; `stale` — нет |
| `label` | подпись из плана (`shell zsh`, `plugin foo`, `env`, `terminfo`) для актуальных |

## PlannedComponent (клиент)

`Component` (адрес, вид, источник) + `label`. План = то, что вход доставил бы этой
цели. Компоненты плана, которых нет ни в одном `RemoteEnv`, — «будут доставлены».

## CleanOutcome

| Поле | Смысл |
|---|---|
| `refused` | активные сессии (`SessionMarker`), из-за которых ничего не удалено |
| `removed` | удалённые пути с освобождённым объёмом (кБ или нет данных) |
| `left` | пути, которые удалить не удалось |

Переходы: `refused` непуст ⇒ `removed` пуст. `left` непуст ⇒ код выхода 50.
