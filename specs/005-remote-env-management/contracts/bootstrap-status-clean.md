# Contract: подкоманды bootstrap `status`, `clean`, `prune` (C-R*)

Дополняет `specs/001-portable-shell-over-ssh/contracts/bootstrap-protocol.md`.
Все три подкоманды запускаются **только потоком**: `sh -s -- <подкоманда> …` со
скриптом в stdin. Поля вывода разделены табуляцией, путь — всегда последнее поле
строки, в которой он есть.

## Поиск каталогов окружения

- **C-R1**: кандидаты — `$HOME/.xxh`, `$TMPDIR/.xxh`, `/tmp/.xxh` в этом порядке, без
  повторов; берётся существующий каталог (не симлинк), принадлежащий текущему
  пользователю. Ни одна подкоманда не создаёт каталогов и файлов при поиске.
- **C-R2**: подкоманды не читают и не удаляют ничего вне найденных каталогов.

## `status`

Для каждого каталога — блок строк, начинающийся с `root`:

```
root	<path>
keep	<секунды|->          # только если есть .keep; «-» — файл пуст
size	<кБ|->               # «-» — нет du
session	<id>	<pid|->	<active|dead>
component	<hash>	<кБ|->
other	<имя>               # прочее в корне каталога и в cache/ (кроме известного)
```

Нет каталогов — пустой вывод, код 0. **C-R3**: `status` ничего не изменяет.

## `clean <force>`

- **C-R4**: если в каком-либо каталоге есть активная сессия и `force` ≠ `1` — выводит
  `active	<pid|->	<id>	<root>` для каждой и завершается с кодом `3`, ничего не
  удалив.
- **C-R5**: иначе удаляет каждый каталог целиком; выводит
  `removed	<кБ|->	<root>` либо, если каталог остался, `left	<root>`. Код `4`, если
  есть `left`, иначе `0`. Нет каталогов — пустой вывод, код 0.

## `prune <force> <hash>…`

- **C-R6**: `hash` — адреса, которые нужно **оставить**; каждый обязан быть 64-символьным
  hex, иначе код `2` без изменений.
- **C-R7**: правило активных сессий — как C-R4.
- **C-R8**: удаляет из `cache/` каждого каталога всё, чьё имя не входит в список
  (включая временные `.tmp.*`); корень, `.keep`, `sessions/`, `boot.sh` не трогает.
  Вывод: `removed	<кБ|->	<path>` / `left	<path>`; коды — как C-R5.

## Запись времени входа

- **C-R9**: `run` в режиме keep пишет в `.keep` значение `XXH_NOW` (секунды Unix от
  клиента) или пустую строку, если оно не задано.
