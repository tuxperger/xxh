# Contract: аутентификация, цепочки и проброс агента во встроенном клиенте (C-J*)

Дополняет `specs/001-portable-shell-over-ssh/contracts/transport-trait.md`.

## Аутентификация

- **C-J1**: явный `-i` — единственный ключ (как раньше).
- **C-J2**: иначе порядок: ключи агента, совпадающие с `IdentityFile` хоста →
  прочие ключи агента (не при `IdentitiesOnly yes`) → файлы ключей, не предложенные
  через агент → keyboard-interactive/пароль.
- **C-J3**: агент — `IdentityAgent` (`none` — без агента), иначе `SSH_AUTH_SOCK`;
  недоступный агент пропускается без ошибки.

## Цепочка

- **C-J4**: `ProxyJump` (список, рекурсивно по псевдонимам, `none` — без цепочки,
  ≤ 8 звеньев, цикл — ошибка) → соединение звено за звеном через `direct-tcpip`.
- **C-J5**: `known_hosts` и аутентификация — на каждом звене, по его конфигурации.
- **C-J6**: ошибка звена — класс «транспорт» (код 10), текст начинается с
  `via <звено>:`.
- **C-J7**: `ProxyCommand` → `BackendUnavailable` с подсказкой `--transport ssh`.
- **C-J8**: на звеньях не открывается ничего, кроме `direct-tcpip`.

## Проброс агента

- **C-J9**: включается `-A`/`--forward-agent` или `ForwardAgent yes`; по умолчанию
  выключен.
- **C-J10**: запрашивается только для канала шелла/команды пользователя; канал
  агента от сервера без разрешения отклоняется.
- **C-J11**: `-A` для контейнерной цели — ошибка использования до подключения.
- **C-J12**: ключи, подписи и обмен с агентом не попадают в журналы.
