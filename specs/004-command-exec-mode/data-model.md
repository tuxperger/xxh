# Data Model: Выполнение одной команды

## ExecCommand (что выполнить)

| Вариант | Данные | Как исполняется на цели |
|---|---|---|
| `Argv` | непустой список аргументов | `exec 'a1' 'a2' …` — без интерпретации шеллом |
| `ShellLine` | строка | `<шелл сессии> -c '<строка>'` |

Правила: список непуст; `Argv` и `ShellLine` взаимоисключающи; каждый аргумент и
строка экранируются одинарными кавычками (`'` → `'\''`).

## Запуск

| Поле | Смысл |
|---|---|
| `tty` | запросить терминал (PTY) вместо раздельных потоков |
| маркер сессии | `<root>/sessions/<sid>` — pid bootstrap (существующий) |
| маркер команды | `<root>/sessions/<sid>.cmd` — pid команды; удаляется очисткой |

## Исходы и коды возврата

| Исход | Код xxh | Сообщение |
|---|---|---|
| команда завершилась с кодом N | N | нет |
| команда убита сигналом S | 128 + S | нет |
| код неизвестен | 255 | нет |
| клиент прерван сигналом S | 128 + S | нет; команда на цели завершена, цель вычищена |
| ошибка xxh | 10 / 20 / 30 / 40 | `xxh: <класс>: …` |
| ошибка использования | 2 | сообщение clap / `xxh: …` |
