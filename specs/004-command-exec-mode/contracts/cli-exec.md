# Contract: режим команды в CLI (C-XC*)

```
xxh <цель> [ОПЦИИ] -- <команда> [аргументы…]
xxh <цель> [ОПЦИИ] -c '<командная строка>'
```

| Опция | Смысл |
|---|---|
| `-- <команда> …` | выполнить команду с точным списком аргументов |
| `-c`, `--command <строка>` | выполнить строку шеллом пользователя |
| `-t`, `--tty` | выделить терминал для команды |

- **C-XC1**: все опции сессии (`--shell`, `--keep`, `-l`, `-i`, `--transport`,
  `--runtime`, `--connect-timeout`) действуют так же, как при входе.
- **C-XC2**: `-c` вместе с аргументами после `--` — ошибка использования (код 2).
- **C-XC3**: `--` без команды, `-t` без команды, режим команды без цели или вместе с
  подкомандой — ошибка использования (код 2), до подключения.
- **C-XC4**: stdout содержит только вывод команды; сообщения об этапах — в stderr и
  только при `-v`/`-vv`/`--debug`.
- **C-XC5**: коды возврата — по таблице data-model.md; ошибке xxh предшествует
  `xxh: <класс>: …`.
- **C-XC6**: при stdin-не-терминале xxh не запрашивает ввод: потребность в пароле или
  парольной фразе — ошибка транспорта (код 10) с объяснением.
- **C-XC7**: без `--keep` цель чиста после завершения команды при любом исходе.
