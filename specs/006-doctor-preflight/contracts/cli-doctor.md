# Contract: `xxh doctor` (C-D*)

```
xxh doctor [<цель>] [--json]
```

Флаги цели (`-l`, `-i`, `--transport`, `--runtime`, `--connect-timeout`, `--shell`)
— как при входе.

- **C-D1**: без цели — только проверки клиента, без сети.
- **C-D2**: с целью — проверки клиента, затем подключение и проверки цели:
  `connect`, `platform`, `tool:*`, `root`, `space`, `shell` (для платформы цели),
  `plugin-target:*` (несовместимые — `warn` «будет пропущен»).
- **C-D3**: на цель ничего не записывается: только `sh -s -- detect|probe|status` и
  `command -v <шелл>`.
- **C-D4**: текст в stdout: секции `client` и `target <метка> (<платформа>)`, по
  строке на проверку — `ok`/`warn`/`FAIL`, сообщение, для `warn`/`fail` — строка
  `→ <действие>`; итог `N passed, M warnings, K failed`.
- **C-D5**: `--json` — один объект:
  `{"client": [Check], "target": {"label": str, "platform": str|null, "checks": [Check]}|null}`,
  `Check = {"id": str, "status": "pass"|"warn"|"fail", "message": str, "action": str|null}`.
- **C-D6**: коды: `0` — без провалов; `1` — есть провал; `10` — цель недостижима
  (проверки клиента и `connect: fail` всё равно выводятся); `2` — использование.

## Вход (FR-009)

- **C-D7**: пакет шелла есть, но без сборки под платформу цели, а шелл на цели
  найден — в stderr заметка `xxh: note: …` (и в режиме одной команды).
- **C-D8**: то же, но шелла на цели нет — ошибка класса shell (код 20) с перечнем
  имеющихся сборок и действием.
