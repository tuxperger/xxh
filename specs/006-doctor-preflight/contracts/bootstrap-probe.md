# Contract: подкоманда bootstrap `probe` (C-P*)

Дополняет `specs/001-portable-shell-over-ssh/contracts/bootstrap-protocol.md`.

- **C-P1**: запускается только потоком (`sh -s -- probe`) и ничего не создаёт и не
  изменяет на цели.
- **C-P2**: вывод — строки, поля через табуляцию, путь — последнее поле:

```
tool	<имя>	<путь|->        # для sh cat mkdir chmod tar gzip zstd du df, в этом порядке
root	<existing|new>	<путь>  # корень, который выбрал бы вход (порядок C-C12)
root	-                       # такого нет
free	<кБ|->                  # свободное место у корня (df -Pk); «-» — нет df или корня
```

- **C-P3**: корень выбирается как у `xxh_resolve_root`, но без `mkdir`: существующий
  `<base>/.xxh` с правом записи — `existing`; иначе `<base>` с правом записи — `new`
  (путь — будущий `<base>/.xxh`).
- **C-P4**: код выхода 0 при любом результате проверок.
