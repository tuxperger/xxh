# Data Model: Быстрый повторный вход

## Component

| Поле | Смысл |
|---|---|
| `kind` | Shell / Plugin / Config (как раньше) |
| `hash` | адрес: blake3 канонического описания дерева (hex, 64 символа) |
| `fmt` | формат архива при доставке: `gz` или `zst`; на адрес не влияет |
| источник | каталог на клиенте (упаковка по требованию) либо готовый архив (сгенерированные компоненты) |

`payload()` → байты архива: из источника-архива, из клиентского кеша либо свежая
упаковка каталога с записью в кеш.

## Каноническое описание дерева

Для каждого элемента в порядке сортировки относительных путей:
`тип (d|f)` · `путь` · `0x00` · `mode & 0o777 (LE u32)` · для файла: `длина (LE u64)` ·
`содержимое`. Корень не включается. Симлинки разыменовываются.

## Запись клиентского кеша

Файл `<hash>.<fmt>`: `blake3(архив)` (32 байта) + архив. Невалидная запись
игнорируется и перезаписывается.
