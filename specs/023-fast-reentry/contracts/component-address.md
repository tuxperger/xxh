# Contract: адрес и подготовка компонента (C-A*)

Уточняет `specs/001-portable-shell-over-ssh/contracts/bootstrap-protocol.md` в части
клиента; протокол цели не меняется.

- **C-A1**: адрес зависит только от путей, прав (`mode & 0o777`) и содержимого файлов
  дерева; не зависит от mtime, владельца, расположения каталога и формата архива.
- **C-A2**: изменение содержимого, имени или прав любого файла меняет адрес.
- **C-A3**: вычисление адреса не упаковывает и не сжимает компонент.
- **C-A4**: `payload()` вызывается только для компонентов, отсутствующих на цели.
- **C-A5**: архив одного дерева побайтно одинаков при любом числе упаковок.
- **C-A6**: архив из клиентского кеша используется только при совпадении контрольной
  суммы; сбой чтения/записи кеша не является ошибкой входа.
- **C-A7**: права файлов после распаковки на цели совпадают с исходными.
- **C-A8**: сгенерированные компоненты с неизменным содержимым имеют неизменный адрес
  между запусками клиента.
