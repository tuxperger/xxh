# Contract: подкоманды bootstrap `verify` и `discard` (C-V*)

Дополняет `specs/001-portable-shell-over-ssh/contracts/bootstrap-protocol.md`.

## `verify <hash>…`

- **C-V1**: выводит строку о корне:
  `root <own|foreign> <ls-права>` (например `root own drwx------`).
- **C-V2**: если нет `find` или `sha256sum` — `unverifiable <утилита>` и больше
  ничего о компонентах.
- **C-V3**: для каждого `hash` (64 hex, иначе код 2): `missing <hash>` либо
  `component <hash>`, затем строки
  `d <путь>` (каталог), `x <путь>` (исполняемый файл), `o <путь>` (не каталог и не
  файл), `f <sha256> <путь>` (каждый файл); пути вида `./…`.
- **C-V4**: ничего не изменяет; код 0.

## `discard <hash>…`

- **C-V5**: удаляет `cache/<hash>` для каждого валидного адреса; код 0.

## Клиент

- **C-V6**: компонент переиспользуется, только если его описание совпадает с
  ожидаемым (множества `d`, `x`, `o` и отображение `f`).
- **C-V7**: несовпадение — предупреждение с адресом/подписью компонента и первым
  различающимся путём, `discard`, повторная доставка, повторная проверка;
  повторное несовпадение — ошибка класса компонента.
- **C-V8**: `unverifiable` — предупреждение один раз за вход; все нужные
  компоненты доставляются заново.
- **C-V9**: корень `foreign` — ошибка класса shell до доставки; права с записью
  для группы/других — предупреждение, все сохранённые компоненты считаются
  непроверенными (C-V8-поведение без отключения проверки доставленного).
- **C-V10**: `recv` с ненулевым кодом — ошибка класса компонента.
