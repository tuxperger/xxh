# Implementation Plan: Целостность сохранённого окружения на цели

**Branch**: `014-remote-cache-integrity` | **Date**: 2026-10-01 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/014-remote-cache-integrity/spec.md`

## Summary

Новая подкоманда bootstrap `verify <hash>…` описывает на цели каталог окружения
(владелец, права) и каждый запрошенный компонент: каталоги, символьные ссылки и
прочие не-файлы, исполняемые файлы и `sha256sum` всех файлов. Клиент сравнивает
это описание с ожидаемым по своему экземпляру компонента (дерево каталога или
архив сгенерированного компонента). Несовпадающие компоненты удаляются
(`discard`) и доставляются заново; после доставки проверяются и они. Если на цели
нет `find`/`sha256sum`, переиспользование отключается для этого входа с
предупреждением. Код выхода `recv` наконец проверяется: неудачная распаковка —
ошибка класса компонента.

## Technical Context

**Language/Version**: Rust 1.85, edition 2024; POSIX `sh` на цели

**Primary Dependencies**: существующие (`sha2` из 008, `tar`, `flate2`, `zstd`)

**Storage**: N/A (формат кеша на цели не меняется)

**Testing**: unit — разбор ответа `verify`, ожидаемое описание компонента (каталог
и архив), сравнение (изменённый файл, лишний файл, симлинк, смена признака
исполняемости), решения по правам; мок-транспорт — несовпадение ведёт к `discard`
и повторной доставке, повтор несовпадения — ошибка, неверифицируемая цель —
предупреждение и доставка; интеграция — изменённый файл и посторонний файл в
сохранённом компоненте обнаружены и исправлены, неизменённое окружение не
передаётся заново, цель без `sha256sum` (контейнер с убранным апплетом —
отдельный каталог `PATH`) — предупреждение, вход работает; замер

**Target Platform**: без изменений

**Project Type**: CLI-инструмент, многокрейтовый workspace

**Performance Goals**: проверка неизменённого окружения ≤ 1 с (SC-003)

**Constraints**: ничего сверх контракта хоста не требуется (используется при
наличии); проверка до любого исполнения из компонента; одинаково для SSH и
контейнеров

**Scale/Scope**: `bootstrap.sh` (`verify`, `discard`), `xxh-core/src/integrity.rs`
(описание, сравнение), `deploy.rs` (ожидаемое описание компонента),
`session.rs` (проверка, повторная доставка, код `recv`), интеграционный тест
