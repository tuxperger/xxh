# Contract: принятие установленного в `xxh sync`

Уточняет 013 `contracts/lock-and-sync.md` C-L6.

- **C-A1**: нет записи lock для объявления (или её `source` отличается от
  объявленного), а под тем же именем установлено содержимое, чей источник совпадает
  с объявленным по происхождению (для flake — ссылка и атрибут), — sync записывает в
  lock `source` объявления, ревизию и хеш установленного и сообщает
  «без изменений». Источник не запрашивается, сборки не запускаются.
- **C-A2**: git-источник принимается только при известной ревизии установки; иначе
  — C-L6.
- **C-A3**: шелл принимается только при известном хеше и наличии сборок под все
  Linux-платформы; иначе — C-L6.
- **C-A4**: установленное из другого источника или отсутствующее — C-L6 без
  изменений.
- **C-A5**: реестр плагинов хранит ревизию установки (`revision` в записи индекса);
  индексы без поля читаются.
- **C-A6**: C-L4, C-L5, C-L7, C-L8 не меняются; read-only lock — принятые записи
  печатаются для переноса (C-L8).
