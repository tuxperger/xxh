# Research: Синхронизация без lock-файла принимает уже установленное

## R1. Как определить «тот же источник»

- **Decision**: `SourceSpec::parse(decl.source)` сравнивается с источником
  установленного через `SourceSpec::same_origin`.
- **Rationale**: индекс хранит разобранную спецификацию, а для flake — ещё и
  закреплённую ревизию (`locked_url`/`revision`), поэтому прямое равенство для flake
  не сработает. `same_origin` уже используется реестром для конфликтов имён (003
  C-F20): для flake сравнивает ссылку и атрибут, для остальных — равенство.
- **Alternatives considered**: сравнение строк конфигурации — индекс строку не
  хранит; хранить строку — лишнее поле и дубль.

## R2. Ревизия git-плагина

- **Decision**: в `IndexEntry` добавить `revision: Option<String>`
  (`#[serde(default, skip_serializing_if = "Option::is_none")]`), заполнять из
  `FetchedPackage::revision` в `Registry::store`. Git-плагин принимается только при
  `revision.is_some()`.
- **Rationale**: запись lock для git без ревизии на другой машине не
  воспроизводится (C-L5 ставит по ревизии). Старые индексы читаются без ошибок; git-
  плагин старой установки один раз ставится из источника — это быстро и сразу
  записывает ревизию.
- **Alternatives considered**: прочитать ревизию из копии пакета — git-метаданные в
  реестр не копируются; принимать без ревизии — нарушает SC-002.

## R3. Какие источники принимаются без ревизии

- **Decision**: `Nix`, `Flake`, `Local` — ревизия в lock для них и при обычной
  установке `None` (у flake пин живёт в спецификации индекса), так что принятая
  запись совпадает с той, что дала бы установка. `Git` — только с ревизией.
- **Rationale**: принятая запись должна быть неотличима от записи после установки.

## R4. Шеллы

- **Decision**: `shellmgr::list()` уже даёт `source`, `revision`, `hash`, `missing`.
  Шелл принимается, если `source` совпадает по `same_origin`, `hash` известен, у
  git-источника есть ревизия и нет недостающих Linux-сборок (условие C-L4 из 013).
- **Rationale**: тот же критерий «установлено полностью», что 013 применяет при
  совпадении с lock.

## R5. Место проверки

- **Decision**: в `sync_plugin`/`sync_shell` перед установкой: если `pinned` нет и
  установленное принимается — вставить запись lock и вернуть `Outcome::Unchanged`.
- **Rationale**: минимальная правка, C-L4/C-L5 не затрагиваются (FR-007).
