# Data Model: Синхронизация без lock-файла принимает уже установленное

## IndexEntry (реестр плагинов, `plugins/index.toml`)

| Поле | Тип | Изменение |
| --- | --- | --- |
| `source` | SourceSpec | без изменений |
| `hash` | string | без изменений |
| `version` | string | без изменений |
| `revision` | string? | **новое**: ревизия источника при установке (git-коммит); отсутствует у старых записей и не-git источников |

Совместимость: поле необязательное, старые индексы читаются, новые записи без
ревизии не пишут поле.

## Установленный шелл (`shells/<имя>/.xxh-shell.toml`)

Без изменений: `source`, `revision`, `hash`, `builds` уже есть.

## LockEntry (`xxh.lock`)

Без изменений. Принятая запись: `source` — строка объявления, `revision` —
ревизия установки (только git), `hash` — хеш установленного содержимого.

## Решение sync для объявления

```text
есть запись lock с тем же source
  ├─ установлено с этим хешем → без изменений            (C-L4)
  └─ иначе → установка по ревизии, проверка хеша          (C-L5)
нет записи / source изменился
  ├─ установлено из того же источника и принимаемо → запись lock, без изменений  (024)
  └─ иначе → установка из источника, новая запись         (C-L6)
```

«Принимаемо»: same_origin; для git — известна ревизия; для шелла — известен хеш и
есть все Linux-сборки.
